# Bug Hunt Report — Local-Only V5

## Newly corrected in this milestone

1. Recurring generation now runs again when the app returns to foreground.
2. Recurring tests no longer depend on the wall-clock date of the test machine; repository clock is injectable.
3. Extreme clock jumps are bounded to avoid years of synthetic recurring drafts.
4. Explicit VOID semantics added: balance/report effect removed while history remains visible.
5. Voiding a Bill payment reopens the Bill.
6. Delete UI no longer refers to cloud/sync tombstones.
7. Local-only onboarding/settings copy no longer presents cloud as the intended future state.
8. SQLite finance writes use WAL + synchronous FULL.
9. Portable backup checks local SQLite integrity before creation and after restore.
10. Backup restore validates IDR-only/domain enums, duplicates, and split totals in addition to FK/ledger checks.
11. PIN/key secure storage on iOS uses non-migrating device-only Keychain accessibility.
12. LockGate re-reads PIN state across lifecycle changes and reports throttling delay.
13. Native hardening script is idempotent and generated by bootstrap.
14. Android raw app-data backup/device transfer is explicitly excluded by generated runner rules.
