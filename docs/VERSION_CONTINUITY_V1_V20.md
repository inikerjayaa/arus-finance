# Arus Finance — Version Continuity V1 → V20

Arus Finance remains one canonical application carried forward through every milestone.
V20 does not replace or fork earlier financial rules. It adds long-session request ordering and state-isolation protections on top of V19.

- V1–V2: product/domain/ledger baseline.
- V3–V7: device-owned local-only core, durability, import, notifications, FTS/security.
- V8–V14: semantic correctness, atomicity, restore/migration catastrophe recovery, self-recovery.
- V15–V17: native-readiness truth gates and reproducible native execution contract.
- V18: production UX/accessibility hardening.
- V19: daily workflow/human-error hardening.
- V20: long-session/state-consistency/performance hardening.

Canonical schema remains v9. Native Flutter/device execution remains a separate proof gate.
